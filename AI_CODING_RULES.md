# AI Coding Rules

These rules are mandatory when AI helps implement the project.

1. Do not introduce new libraries/frameworks without approval.
2. Do not change architecture without approval.
3. Do not modify database schema without explaining migration impact first.
4. Do not generate features outside the current task.
5. Check `AI_CURRENT_TASK.md` before implementation.
6. Follow existing naming conventions.
7. Keep files/functions focused on one responsibility.
8. Never expose secrets, credentials, or real customer data.
9. Explain significant changes before implementation.
10. Ask for the implementation plan first, then implement one step at a time.
11. After implementation, explain the code and review it against the relevant requirement.

AI is an assistant. Amit Kunwar remains the engineer responsible for requirements, review, testing, and final decisions.
