# Workflows — P002: Small Business Management System

## Login
```
Login → Validate credentials → Dashboard
```

## Core Sale Loop
```
Dashboard
→ Select/Search Product(s)
→ Enter Quantity
→ Validate Stock
→ Calculate Total
→ Select Customer (optional — omit for a walk-in sale)
→ Capture Payment Method (optional, if applicable)
→ Save Sale
→ Reduce Inventory
→ Generate Invoice
→ Sales History
```

## Product Management
```
Products page → Add/Edit Product → Validate → Save → Product list updates
```

## Backup
```
Settings/Admin → Export/Backup → File saved
```
